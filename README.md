Active Directory Domain Services (AD DS) quraşdırılması, Domain Controller infrastrukturunun qurulması, Təşkilati Vahid (OU) strukturlarının dizaynı, istifadəçi və qrupların idarə edilməsi. Group Policy (GPO) vasitəsilə baza istifadəçi və kompüter siyasətlərinin tətbiqi, Help Desk ssenarilərinin (istifadəçi yaradılması, şifrələrin sıfırlanması) simulyasiyasını praktiki olaraq etmişəm.

Routing and Remote Access (RRAS):  Təhlükəsiz xarici şəbəkədən daxili şəbəkəyə girişi simulyasiya etmək üçün RRAS vasitəsilə statik/dinamik marşrutlaşdırma (Routing), NAT və Port Forwarding tənzimləmələri. Client-to-Site VPN serverlərinin (PPTP, L2TP, SSTP, IKEv2) qurulması və testi, Uzaqdan Masaüstü (RDP) bağlantılarının yoxlanılması
